# Программа нахождения кратчайшего пути в графе

*A Program for Finding Shortest Path in a Graph*

Настольное приложение для Windows, которое позволяет построить ориентированный взвешенный граф
(мышью или из файла) и наглядно, по шагам, показывает работу алгоритмов поиска кратчайших путей:

- **алгоритм Дейкстры** — для графов без рёбер отрицательного веса;
- **алгоритм Беллмана–Форда** — работает с отрицательными весами и находит циклы отрицательного веса
  (для вершин за таким циклом выводится расстояние −∞).

Реализация соответствует техническому заданию и пояснительной записке, но собственными средствами:
вместо библиотеки GraphX используется собственный элемент управления для отрисовки графа.

## Требования

- Windows 10 или новее;
- [.NET 9 SDK](https://dotnet.microsoft.com/download) для сборки (для запуска достаточно .NET 9 Desktop Runtime).

## Сборка и запуск

```bash
dotnet run --project src/Pathfinder.App
```

Тесты:

```bash
dotnet test
```

Готовый к переносу комплект (exe + dll, установка не требуется):

```bash
dotnet publish src/Pathfinder.App -c Release -o publish
```

Файл графа можно передать в командной строке (`Pathfinder.exe граф.graph`) — он откроется при запуске.
Примеры лежат в папке `Samples` рядом с программой.

## Работа с программой

| Действие | Как выполнить |
|---|---|
| Добавить вершину | режим «Редактирование», клик по пустому месту |
| Добавить ребро | протянуть мышью от одной вершины к другой, ввести вес |
| Переименовать / удалить вершину | клик по вершине |
| Изменить вес / удалить ребро | клик по ребру или его весу |
| Переместить вершину | перетащить её в режиме «Перемещение» |
| Сдвинуть / масштабировать поле | перетащить пустое место; колесо мыши; средняя кнопка |
| Запустить алгоритм | кнопка «Дейкстра» или «Беллман–Форд», затем выбрать начальную вершину |
| Управлять анимацией | «Пауза», «Шаг», «В конец», «Сброс», ползунок скорости |
| Увидеть кратчайший путь | после завершения навести курсор на вершину или выбрать строку таблицы |

Во время анимации над каждой вершиной показывается её текущая метка (расстояние), справа выводится
пошаговый журнал алгоритма и таблица расстояний; цвета поясняет легенда (меню «Вид → Обозначения»).

## Формат файла

Текстовый файл (UTF-8) — список рёбер, по одному на строку:

```text
# комментарий
A B 4.5        # ребро A → B с весом 4.5
C              # вершина без рёбер
@ A 10 20      # (необязательно) положение вершины A на поле
```

- элементы разделяются пробелами, дробная часть отделяется точкой;
- имена вершин — до 32 символов, без пробелов и символов `#`, `@`;
- рёбра ориентированные; петли и повторные рёбра не допускаются;
- вес по модулю не больше 10⁹; не более 1000 вершин и 20 000 рёбер;
- вершины без указанного положения располагаются по окружности.

При открытии файл полностью проверяется; если в нём есть ошибки, программа сообщает номера строк
и причину, а текущий граф не меняется. При сохранении записываются положения всех вершин и все рёбра.

## Устройство решения

```text
src/Pathfinder.Core       логика без зависимостей от UI
  Model/                  неизменяемый граф и правила его корректности
  Algorithms/             Дейкстра, Беллман–Форд; каждый возвращает трассу шагов и результат
  IO/                     чтение и запись файла графа с проверкой данных
  Layout/                 автоматическое размещение вершин
  Visualization/          состояние анимации как чистая функция (состояние, шаг) → состояние
src/Pathfinder.App        WPF-приложение
  Controls/GraphCanvas    отрисовка графа, масштаб, жесты редактирования
  Dialogs/                ввод имени/веса, выбор начальной вершины
  MainWindow*.cs          редактирование, файлы, проигрывание алгоритмов
tests/Pathfinder.Core.Tests  модульные тесты (xUnit), включая сверку с алгоритмом Флойда–Уоршелла
```

Алгоритм выполняется сразу целиком и записывает трассу событий (выбор вершины, релаксация ребра,
начало прохода и т. д.). Анимация лишь проигрывает эту трассу по таймеру, поэтому пауза, пошаговый режим
и перемотка в конец не влияют на результат. На очень больших графах трасса ограничена 100 000 шагами;
итоговый результат при этом всегда вычисляется полностью.
